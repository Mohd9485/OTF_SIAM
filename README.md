# Optimal Transport Filter (OTF)

Code accompanying the paper:

> **Error Analysis of Triangular Optimal Transport Maps for Filtering**
> M. Al-Jarrah, B. Hosseini, N. Jin, M. Martino, A. Taghvaei

The OTF is a nonlinear filter that approximates the Bayesian update with an optimal transport map from the prior (forecast) ensemble to the posterior. The map is learned at each assimilation step by solving the dual (max–min) optimal transport problem with two neural networks: a potential f and a transport map T. The OTF is compared against the Ensemble Kalman Filter (EnKF) and Sequential Importance Resampling (SIR) on three benchmarks: a static problem with a bimodal posterior, the Lorenz 63 system, and the Lorenz 96 system.

## Repository Structure


Each folder contains its own `README.md` with the experiment details, the running order, and the files each script produces.

## Dependencies

Install the requirements with:

```bash
pip install torch numpy matplotlib seaborn POT smac
```

| Package | Purpose |
|---|---|
| `torch` | Neural network training (OTF) |
| `numpy` | Numerics, data generation, EnKF and SIR |
| `matplotlib` / `seaborn` | Plotting |
| `POT` | Wasserstein (W₂) and sliced Wasserstein (SW₂) distances |
| `smac` | Hyperparameter tuning (optional; installs `ConfigSpace` and `dask`) |

The code was tested with Python 3.13, PyTorch 2.11, NumPy 2.4, Matplotlib 3.10, seaborn 0.13, POT 0.9.6, and SMAC 2.3.

## Quick Start

Hyperparameters have already been tuned and are stored in each folder's `param.py`. To reproduce the figures:

```bash
# Figures 3 and 4 (Bimodal)
cd "Bimodal static example"
python bimodal_static_example.py     # Figure 3
python error_and_time_vs_dim.py
python error_vs_particles.py         # with d = 2 (see the folder README)
python error_vs_particles.py         # with d = 10
python Import_Data.py                # Figure 4

# Figures 5 and 6 (Lorenz 63)
cd "../Lorenz 63"
python main.py
python OTF_Poincare.py
python Import_DATA_L63.py            # Figures 5 and 6

# Figure 7 (Lorenz 96)
cd "../Lorenz 96"
python main.py
python Import_DATA_L96.py            # Figure 7
```

The data-generating scripts (`main.py`, `error_and_time_vs_dim.py`, `error_vs_particles.py`, `OTF_Poincare.py`) save their results in the same folder; the `Import_*` scripts only load these results and plot them, so figures can be restyled in seconds without rerunning the experiments.

## Hardware

All scripts use a GPU when one is available (the main experiment scripts pick the least-loaded one) and fall back to the CPU otherwise; they also run on a single GPU, in which case the two OTF runs that `main.py` normally places on separate GPUs share it. A GPU is strongly recommended: the full experiments take several hours on GPUs (about 7 hours for Lorenz 96 on two GPUs) and would take much longer on a CPU. The plotting scripts do not need a GPU.
